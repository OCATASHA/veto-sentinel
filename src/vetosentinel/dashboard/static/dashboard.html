        Veto Sentinel watches three things about the news and compares each one with what is normal for it. A reading of 0 means "a typical day"; the higher the number, the more unusual it is. Anything at or below normal counts as zero, so a calm signal can never hide a stressed one.

              How bots stay safe

              1. Veto Sentinel sends a heartbeat every second

                Each one carries the current level and a running number, like a pulse.

              2. The bot checks its own copy before every order

                That check takes nanoseconds and never waits on the network.

              3. Anything odd? The bot stops itself

                No heartbeat for 3 seconds, a garbled or missing message → it stops trading until two good heartbeats arrive.
